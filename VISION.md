# Vision

## Leetcode Reminder

Android приложение, в котором решают алгозадачи с LeetCode на Go, 
собирая решение из готовых блоков кода
(похоже на решение задач в Duolingo).

### Для кого

Для людей, которые готовятся к алгособесам
и хотят тренироваться там, где нет ноутбука и нормального интернета
(в электричке в академгородок).

### Какую проблему решает

- **Чтение решений в интернете выматывает.** Нужно находить задачу на LeetCode,
  находить сайт с решением или спрашивать ИИ, выбирать наиболее подходящий паттерн,
  выбирать лучшее решение по времени и памяти,
  выбирать среди лучших решений по времени и памяти те, которые читаемо хорошо написаны.
  Затем пролистывать решение и запоминать.

- **Писать код на телефоне невозможно, а читать недостаточно.**
  Понимание решения не гарантирует, что без практики ты сам его напишешь.

- **Задачи забываются.** Решённая месяц назад задача на собеседовании
  всплывает как незнакомая.

### Как решает

1. **Сборка решения из блоков.** Решение на Go нарезано на блоки.
   Их нужно расставить в правильном порядке. Приходится думать о структуре
   алгоритма.
2. **Возможность посмотреть подсказки.** Сначала сложность, потом паттерн,
   потом идея, потом ключевая строка.
3. **Возможность повторения.**
4. **Полностью офлайн.**

### Чем это не является

- Не замена LeetCode: код здесь не пишется и не запускается.
- Не редактор задач: задачи готовятся и поставляются вместе с приложением.
- Не многоязычное: решения только на Go.
