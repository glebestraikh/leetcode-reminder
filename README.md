# Leetcode Reminder

Android приложение, в котором решают алгозадачи с LeetCode на Go,
собирая решение из готовых блоков кода
(похоже на решение задач в Duolingo).

Для кого приложение и какие проблемы оно решает можно посмотреть в [VISION.md](VISION.md).

**Стек:** `Kotlin` `Jetpack Compose` `Coroutines` `ViewModel` `StateFlow` и другие

### Пользовательские сценарии

- **Просмотр задач.** Можно открыть приложение, посмотреть список задач, выбрать тему. Внутри темы задачи идут от простых к сложным.

- **Выбор задачи.** Можно открыть выбранную задачу, прочитать условие, примеры и ограничения.

- **Подсказки.** Можно открыть подсказки
(сложность по времени и памяти, идея, полное решение).

- **Сборка решения.** Можно заполнить пропуски в коде перемешанными блоками
  и проверить решение.

- **Оценка.** После решения можно оценить, насколько хорошо запомнилось решение.

- **Повторение.** По последней оценке видно, какие задачи стоит повторить.

### Критерии готовности

- В приложении есть минимум 30 задач на Go.
- Задачи сгруппированы по темам и отсортированы по сложности внутри темы.
- Есть подсказки.
- Решение собирается из блоков.
- При ошибке видно, какой блок стоит не на месте.
- После решения можно оценить, насколько хорошо запомнилось решение.
- В списке видна последняя оценка запоминания.
- У каждой задачи виден счётчик повторений.
- Прогресс сохраняется после закрытия приложения.
- Всё работает без интернета.
