# Leetcode Reminder

Android приложение, в котором решают алгозадачи с LeetCode на Go,
собирая решение из готовых блоков кода
(похоже на решение задач в Duolingo).

Какие проблемы решает это приложение и для кого оно можно посмотреть в [VISION.md](VISION.md).

#### Стек

`Kotlin` `Jetpack Compose` `Coroutines` `ViewModel` `StateFlow` `будет пополняться`
