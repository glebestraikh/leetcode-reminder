# Leetcode Reminder

Android приложение, в котором решают алгозадачи с LeetCode на Go,
собирая решение из готовых блоков кода
(похоже на решение задач в Duolingo).

Какие проблемы решает это приложение и для кого оно можно посмотреть в [VISION.md](VISION.md).

#### Стек

`Kotlin` `Jetpack Compose` `Coroutines` `ViewModel` `StateFlow` `будет пополняться`

### Основные пользовательские сценарии

- **Просмотр задач.** Можно открыть приложение, посмотреть список задач, отфильтровать по паттерну или сложности.

- **Выбор задачи.** Можно открыть выбранную задачу, прочитать условие, примеры и ограничения.

- **Подсказки.** Можно смотреть подсказки по одной:
  подходящая сложность для собеса, паттерн, идея, ключевая строка, посмотреть решение.

- **Сборка решения.** Можно расставить перемешанные блоки кода в правильном порядке
  и проверить решение.

- **Оценка.** Можно проставить оценку по сложности решенной задаче.

- **Повторение.** Приложение предлагает задачи, которые было бы хорошо повторить.

### Критерии готовности

- В приложении есть минимум 30 задач на Go.
- Список задач показывает сложность и статус, работают фильтры.
- Есть подсказки.
- Решение собирается из блоков, проверка отличает правильный порядок от неправильного.
- При ошибке видно, какой блок стоит не на месте.
- По оценкам у каждой задачи меняется индикатор запоминания.
- После решения можно поставить оценку по сложности.
- У каждой задачи виден счётчик повторений.
- У каждой задачи виден индикатор запоминания.
